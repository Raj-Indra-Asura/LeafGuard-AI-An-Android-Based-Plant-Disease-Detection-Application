# 🚀 START HERE — The One Official Starting Sequence

There are several navigation documents in this repository (`README.md`, `HOW_TO_NAVIGATE.md`, `LEARNING_PATH.md`, `QUICK_NAV.md`). **This file is the single source of truth for the order in which to read them.** If any other document suggests a different starting order, follow *this* one.

## The Orientation Sequence (do these once, in this exact order)

1. **[Pre-Week-01 Setup Checklist](README.md#pre-week-01-setup-checklist-do-this-first)** — install Android Studio, Python 3, an emulator, and Git *before anything else*.
2. **[README.md](README.md)** — what LeafGuard AI is, what you will build, and how to **pick your track** (Kotlin in [`android-app-kotlin/`](android-app-kotlin/) is primary/recommended; Java in [`android-app/`](android-app/) is the behavior-identical secondary — if unsure, choose Kotlin).
3. **[COURSE_OVERVIEW.md](COURSE_OVERVIEW.md)** — the 12-week course at a glance.
4. **[LEARNING_RULES.md](LEARNING_RULES.md)** — the rules you commit to (no skipping validation, evidence every week).
5. **[PRODUCT_PROGRESS_MAP.md](PRODUCT_PROGRESS_MAP.md)** — the official cumulative-% model: what % of the product exists after each week.
6. **[GLOSSARY.md](GLOSSARY.md)** — skim it now; return whenever a term is unfamiliar.
7. **➡️ Begin [Week 01](roadmap/week-01-project-understanding/README.md).**

That's it. You do **not** need to read `HOW_TO_NAVIGATE.md`, `LEARNING_PATH.md`, or `QUICK_NAV.md` before starting — they are *reference* tools:

- [`LEARNING_PATH.md`](LEARNING_PATH.md) — hub with links to every week's materials.
- [`QUICK_NAV.md`](QUICK_NAV.md) — "I want to…" fast lookups once you're underway.
- [`HOW_TO_NAVIGATE.md`](HOW_TO_NAVIGATE.md) — explains the navigation system itself.

## The Within-Week Order (identical every week)

Every week folder in [`roadmap/`](roadmap/) contains exactly **7 files**. Work through them in this fixed order — it is stated once here and repeated in every week README's navigation footer:

| Step | File | Purpose |
|------|------|---------|
| 1 | `README.md` | Week overview, objectives, prerequisites, product state after this week |
| 2 | `learning-notes.md` | Theory — every concept taught from zero, *before* any code |
| 3 | `exercises.md` | Isolated practice before touching the real product |
| 4 | `build-task.md` | Numbered steps that build this week's increment of the real app |
| 5 | `validation-checklist.md` | Pass/fail gate + the 🎬 Milestone Demo — **do not advance until all pass** |
| 6 | `quiz.md` | Knowledge check |
| 7 | `reflection.md` | Consolidate what you learned |

**Every week, also:** tick your boxes in [`progress-tracker.md`](progress-tracker.md) (including the cumulative % line) and save screenshots/logs as evidence.
